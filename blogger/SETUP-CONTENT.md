## THE 6 NOTICE LABELS — exact spelling (case-sensitive)

Copy these exactly into the Labels field of each post. Add `Notice` to every notice post as well.

| # | Label | When to use it |
|---|---|---|
| 1 | `General Notices` | General / day-to-day notices |
| 2 | `Admission Notices` | Admission circulars, merit lists, admission dates |
| 3 | `Examination Notices` | Exam routines, admit cards, exam instructions |
| 4 | `Class Routine` | Class routine PDFs |
| 5 | `Results` | Any published result |
| 6 | `Important Announcements` | Urgent/breaking — also feeds the homepage ticker |

Extra labels you may also use: `Notice` (all notices), `News` (news/events posts).

**Label page URLs (these work as soon as a post with that label exists):**
- `/search/label/General%20Notices`
- `/search/label/Admission%20Notices`
- `/search/label/Examination%20Notices`
- `/search/label/Class%20Routine`
- `/search/label/Results`
- `/search/label/Important%20Announcements`
- `/search/label/Notice`

## PDF HOW-TO (for every routine / result post)

1. PDF Google Drive-এ আপলোড করুন → Share → **Anyone with the link → Viewer** → Copy link.
2. পোস্টে লিংকটি যোগ করুন (টেক্সট সিলেক্ট করে লিংক আইকন)।
3. Incognito উইন্ডোতে লিংকটি খুলে যাচাই করুন — লগইন ছাড়া খুললে ঠিক আছে।
